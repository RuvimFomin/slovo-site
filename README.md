# Сайт пространства «СЛОВО»

Маркетинговый лендинг с развитием в контентный сайт. Astro 7 + Tailwind CSS 4,
статическая генерация, файловая CMS на content collections.

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # сервер разработки → http://localhost:4321
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр собранной версии
```

## Как опубликовать новую встречу (без изменения кода)

1. Скопируйте любой файл из `src/content/events/` под новым именем,
   например `vstrecha-8.md`.
2. Заполните поля в шапке файла (frontmatter):
   - `number`, `title`, `description` — номер, название и краткое описание;
   - `date` (ГГГГ-ММ-ДД), `startTime`, `endTime` — дата и время;
   - `bibleReference`, `culturalProgram` — библейский текст и культурная программа;
   - `registrationUrl` — ссылка на регистрацию именно этой встречи в Timepad;
   - `isFree: true` — только когда бесплатный вход подтверждён;
   - `status: "published"` — встреча видна на сайте и становится ближайшей.
3. Текст под шапкой — подробная программа (поддерживается Markdown).
4. Выполните `npm run build` и опубликуйте `dist/` на хостинге.

Ближайшая встреча на главной и на странице `/vstrecha/` определяется
автоматически как ближайшее опубликованное событие в будущем. Устаревшая
карточка скрывается и на клиенте: если сборка не обновлялась, посетитель
увидит блок «Программа ближайшей встречи готовится», а не прошедшую встречу.

## После того как встреча прошла

1. В её файле поменяйте `status` на `"completed"`.
2. Добавьте ссылки на запись в `videoUrls` (youtube / rutube / vk) —
   блок «Запись встречи» появится на странице события автоматически.
3. При желании добавьте запись в `src/content/lectures/` — она попадёт
   в блок «Записи лекций» на главной.

## Статусы событий

| Статус | Поведение |
|---|---|
| `draft` | Нигде не отображается |
| `published` | Участвует в выборе ближайшей встречи, есть в афише |
| `completed` | Только в архиве, со ссылками на записи |
| `cancelled` | Страница доступна с пометкой об отмене |

## Лекторы

`src/content/speakers/*.json` — имя, роль, биография, фото, ссылки.
В событии лекторы указываются списком `speakerIds` (имя файла без расширения).
Архитектура не привязана к одному лектору.

## Настройки сайта

`src/data/site.ts` — адрес, метро, соцсети, контакт, домен, номер счётчика
Яндекс Метрики. Счётчик подключается только когда указан реальный номер.

### События аналитики

Размечены атрибутами `data-goal` (клики) и `data-goal-view` (показы):
`view_event`, `click_registration`, `click_telegram`, `click_youtube`,
`click_route`, `click_contact`, `view_lecture`, `play_video`.
UTM-метки первого визита сохраняются и автоматически добавляются
ко всем ссылкам регистрации (`data-utm`).

## Домен и SEO

Домен задан в двух местах — заменить перед публикацией на финальный:

- `astro.config.mjs` → `site`
- `src/data/site.ts` → `url` (и `public/robots.txt` → строка Sitemap)

## Что требует наполнения (отмечено TODO в коде)

- Данные ближайшей встречи: описание, библейский текст, культурная программа,
  точная ссылка Timepad, подтверждение бесплатного входа.
- Биография Марка Хорева и его фотография.
- Фотография входа и пошаговая инструкция по проходу (`Location.astro`).
- Юридические документы (`privacy.astro`) — предоставляет Андрей Наприенко.
- Прямые ссылки на видеозаписи лекций.
- Контактный e-mail посетителей.

## Ограничение по картам

Нельзя создавать карточку организации «СЛОВО» в Яндекс Картах и 2ГИС.
На сайте используется только ссылка на построение маршрута к адресу —
не встраивать iframe-карты с самовольно созданной точкой.
